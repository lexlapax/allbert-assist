# Allbert v1.6.0 Knowledge Central — LLM Wiki Flagship

Stage 2 of the Knowledge Central feature. Stage 1 shipped the derived page graph
over claims at v1.5; this release adds the document layer, the schema, and the
composite query that make it a knowledge system rather than a memory view.

Constraining ADRs: **ADR 0094** (Knowledge Central and the derived wiki
projection), **ADR 0095** (schema authority and untrusted source ingestion).
Companion: `docs/plans/v1.6-request-flow.md`.

Status: **planned — triad drafted 2026-07-30, readiness passes not yet run.**
No Locked Decision below is operator-signed.

## Build Progress

Not started.

## Purpose

Turn the Stage 1 page graph into a compiled knowledge layer over the operator's
own documents, with the maintenance loop the pattern depends on and the trust
boundary the pattern lacks.

1. **Document ingest.** Sources from connected roots and the Artifacts store
   become first-class inputs with ResourceURIs and grants. Detection is
   automatic, deterministic, and zero-egress; spend is bounded and disclosed.
2. **A synthesis cache that makes rebuild free.** LLM synthesis is stored as a
   durable content-addressed artifact keyed by source, schema, page type, model
   profile, and prompt version. Rebuild replays the cache; only new or changed
   sources cost a model call. Pages stay derived without rebuild becoming a
   recurring bill.
3. **The operator schema, safely.** An operator-authored schema document that
   co-evolves, with a confirmed review on change — and a typed parse that makes
   authoritative-tier escalation impossible rather than merely reviewed.
4. **Untrusted sources, contained.** Clipped web content is assumed hostile.
   Injection may produce a wrong page; it may not produce a permission grant, an
   action, egress, a write outside the projection, or an untraceable claim.
5. **One question, three layers, labelled.** Composite query across Knowledge
   pages, Memory kept claims, and Search Central, with every fact tagged by the
   layer it came from. The operator never chooses a tool.
6. **Lint that reasons.** Deterministic Stage 1 checks plus LLM-assisted
   investigation-gap and provenance-conflict analysis.

## Locked Decisions

Numbering continues from the v1.5 plan. None is operator-signed yet.

14. **Sources are untrusted data, never instructions.** The six structural
    properties of ADR 0095 §4 are binding and individually eval-bound.
15. **Ingest output is a typed page structure.** The model never names a path.
    Allbert writes files through the typed contract.
16. **Ingest writes only under `projections/knowledge/`**, grants no permission,
    triggers no action, and causes no egress beyond the ingest call.
17. **`:knowledge_source_ingest` is a new policy class**, resolved through
    Security Policy, following the `Channels.InboundTrust` precedent.
18. **Schema authority is tiered and enforced by the parser.** Authoritative keys
    do not exist in the schema grammar. (ADR 0095 §1)
19. **Schema lives at `<HOME>/knowledge/schema.md`**, durable, any editor. A
    digest change requires confirmed review before taking effect. (ADR 0095 §2)
20. **Synthesis cache key** is
    `(source_digest, schema_digest, page_type, model_profile_id, prompt_template_version)`.
    Durable, backed up, outside `projections/`. Purged on source removal and on
    Forget of a contributing claim.
21. **Invalidation is disclosed before it happens.** A schema or model change
    states "invalidates N syntheses, approximately X tokens" at the confirming
    surface.
22. **Detection and spend are separate.** Detection is automatic and zero-egress.
    Ingestion auto-proceeds only within `knowledge.ingest.auto_budget_tokens`;
    beyond it, sources queue with provider and estimate named. Budget zero yields
    pure staged review.
23. **Ingest uses `model_roles.capable`.** Egress is always named before it
    occurs.
24. **Composite query carries three binding properties:** no new authority (each
    layer answers under its own), most-restrictive scope wins (DM elevation is
    requested through the Search seam, never reimplemented), and
    operator-initiated only.
25. **Knowledge never enters prompt assembly.** Unchanged from Stage 1. The
    prompt budget is untouched.
26. **Stage 2 contradiction detection is narrowed** to provenance conflicts on
    typed fields. Free-text semantic contradiction across documents is parked.

## Operator-Visible Win

The operator drops papers, articles, and clippings into a folder they already
use. Allbert notices, tells them what it would cost, and — once approved —
compiles them into the same browsable page graph their own memory already feeds.
Asking "what do I know about X" returns one answer assembled from documents,
memory, and conversation history, with each fact labelled by where it came from.

## Security Posture

This release introduces the first path where untrusted third-party text reaches
a model that produces files. The posture is containment, not detection: injection
is assumed present, and the design bounds what it can achieve.

- Source content renders into a delimited, explicitly non-instruction region.
- Ingest output is typed; the model never names a path.
- Writes are confined to `projections/knowledge/`; no permission grant, no action
  trigger, no egress beyond the ingest call.
- Every page records source provenance; a poisoned page is traceable.
- Pages are derived; removing the source and rebuilding removes the poisoning.
- `:knowledge_source_ingest` gates every ingestion.
- The schema document grants no permission by itself and cannot express
  authoritative-tier keys.

Detecting injection *content* is explicitly not attempted.

## Non-Goals

Knowledge-in-prompt; semantic, embedding, vector, or fuzzy retrieval; free-text
semantic contradiction across documents; multi-user or shared wikis; a developer
sidecar document; any editor-specific integration; claim origination from
documents (ADR 0089 stands); and the guided persona, which follows in a 1.6
point release. (The pre-resequencing text said 1.7 while the roadmap said 1.8;
both predated this release becoming v1.6, and the point release tracks it.)

## Validation Design (churn guardrails, binding)

- Every ADR 0095 §4 property is an individually named eval row, red-first against
  a seeded hostile document.
- Cache correctness is proven by rebuild determinism: same sources, same schema,
  same model profile, zero model calls, byte-identical pages.
- Composite authorization is adversarial: a fact denied by its owning layer must
  not surface because another layer was queried.
- Egress accounting is exact: token estimates shown at approval are compared to
  actual usage and recorded.

## Definition Of Done

- Documents from connected roots and Artifacts ingest through
  `:knowledge_source_ingest`, producing typed pages with source provenance.
- A hostile document cannot grant permission, trigger an action, cause egress,
  write outside the projection, or produce an untraceable page — each proven by a
  named eval row.
- Rebuild with unchanged sources makes zero model calls and produces identical
  pages; invalidation is disclosed with counts and estimates before proceeding.
- The schema document co-evolves under confirmed review, and authoritative-tier
  keys are rejected by the parser rather than honoured.
- Composite query returns one answer across three layers with per-fact labels,
  under per-layer authorization and most-restrictive scope.
- Automatic ingestion never exceeds the token budget without approval; every
  approval names provider and estimate; actual usage is recorded against it.
- Knowledge remains operator-initiated and absent from prompt assembly.
- Dual-host composite-query latency recorded per host, neither averaged away.
- `release.v16` composes the exact `release.v15` prefix and is green at one
  clean pushed SHA; `v1.6.0` is built, signed, published, tap-installed, and
  revalidated; ADR 0094 and ADR 0095 are Accepted.
