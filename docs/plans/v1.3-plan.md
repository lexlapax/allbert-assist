## Purpose

Ship the 1.3 flagship: Allbert builds a long-term memory of its operator —
facts and preferences consolidated periodically from interaction history,
not only explicit "remember this" asks — behind an explicit review
boundary, and consults it at prompt-formation time so answers land
zero-shot.

1. **System-consolidated memory proposals.** A periodic, bounded, local,
   audited consolidation job reads durable usage history (conversations,
   traces, objectives) and writes deduplicated, provenance-carrying,
   sensitive-filtered proposals into an inert system-proposed tier
   (ADR 0089 §2–§3).
2. **The consent boundary holds.** Proposals are never retrievable into
   any prompt while unreviewed; only operator-reviewed `:kept` entries
   enter context; bulk-accept/edit/reject review exists on web and CLI.
   "Memory review remains explicit" survives the flagship that most
   tempted it.
3. **Prompt-time context that measurably works.** Retrieval consults LTM
   at the direct-answer seam within an explicit budget; the seeded-facts
   acceptance corpus proves zero-shot answering and records the token /
   interaction-count delta from real runs.
4. **Retrieval that survives its own success.** Index-backed candidate
   listing replaces the per-turn full filesystem scan; durable facts
   survive the recency floor; retrieval cost is measured flat-ish against
   the large-corpus fixture.
5. **STM contract formalized.** Working memory gets its data-safety
   definition and nested patch semantics (the folded v0.14 gaps) without
   becoming persistent.
6. **Research first, honestly.** The M1 research note resolves the
   remaining LD-R placeholders with evidence, the operator signs the
   outcomes (including the consolidation default posture, the measured
   precision/recall floors, and the FTS in/out call), and ADR 0089 is
   amended before implementation consumes it.
7. **Facts stay current, and being wrong stays auditable.** A fact the
   operator later contradicts is superseded, not duplicated: the prior
   entry is retired with a linked supersedes chain, retrieval stops
   returning it, and it remains on disk and inspectable. Consolidation
   proposes the retirement; only operator review enacts it. Retrieval
   asks "valid as of when", defaulting to now.
8. **Allbert ships knowing what it is made of.** The packaged binary
   carries its own licence, notice, and complete third-party attribution,
   generated from the shipped application set and gate-enforced against
   drift and against non-permissive dependencies.

    Memory entries carry valid time (`valid_from`, `valid_to`) and
    transaction time (`recorded_at`, `retracted_at`) plus `supersedes`,
    `superseded_by`, and `revision` — all additive frontmatter, all
    nullable, pre-1.3 entries reading as valid/never-retracted.
    Contradiction retires the prior entry non-destructively and links the
    chain; nothing is overwritten or deleted. Detection is deterministic
    (same subject/predicate/namespace; newest-valid-wins by recorded
    instant); model assistance may only propose that two claims concern
    the same subject, never decide the winner; ambiguous conflicts go to
    the operator unresolved. Retrieval is as-of with an **explicit**
    parameter defaulting to now — as-of is never inferred from natural
    language (ADR 0089 §7).
19. **Only operator-authored content originates a fact (operator,
    readiness pass).** Extraction reads operator-authored turns; assistant
    turns are disambiguation context only and can never be the origin of
    a proposal. This is the memory-side reading of "model output grants no
    authority"; without it Allbert's own speculation returns as a proposal
    carrying real provenance. Gate-bound by
    `v13-assistant-turn-not-a-fact-001`. Conversations are the primary
    source; traces and objectives are supplementary and may legitimately
    be empty when `runtime.trace_default` was never enabled.
20. **A recall floor gates beside the precision floor (derived).** A
    fail-closed extractor passes a precision-only gate by proposing almost
    nothing, satisfying the gate while failing the Operator-Visible Win.
    M1 sets both floors on the same real seeded corpus; M3 gates both;
    both are release blockers.
21. **The proposal tier has backpressure (derived).** Unreviewed
    proposals are capped (`memory.consolidation.max_pending`); at the cap
    a run proposes nothing, records the reason in its run summary, and
    surfaces a review prompt rather than growing an unbounded pile that
    every later run must re-scan and re-dedupe against. Reaching the cap
    is a recorded no-op, never a silent drop.
22. **Packaging license compliance is M0.a (operator, readiness pass).**
    Its own early milestone rather than a rider on M9, so the release
    step is proven long before RC. Independent of the memory spine
    (workstream WS-D) and buildable in parallel from build start.

## Operator-Visible Win

Tell Allbert your world once — or just use it — and it starts knowing.
After a while it quietly proposes: "you prefer metric units", "your
daughter's school is X", "you deploy on Fridays" — each with where it
learned it. You keep the true ones in one sweep, fix or reject the rest,
and from then on answers start from what you kept: no re-explaining, fewer
follow-ups, visibly fewer tokens.

When something about you changes, you say so once and Allbert notices the
contradiction — it proposes retiring the old fact instead of quietly
believing both. You approve, and it stops using the stale one; the old
belief stays on record with the date it stopped being true, so you can
always see what it thought and when it changed its mind. And when it has
nothing on a subject, it says so rather than inventing a preference you
never stated.

Nothing enters its memory of you without passing your eyes, nothing leaves
it without passing your eyes either, everything stays on your machine, and
one switch turns the whole consolidation loop off.

## Security Posture

This release adds a background reader and a proposal tier — and no grant:

- **Consolidation grants nothing.** Proposals are inert entries; they
  carry no action authority, cannot change settings, and never enter a
  prompt unreviewed. The ADR 0045 advisory posture is preserved and
  extended.
- **The review boundary is the authority boundary.** Keep/reject rides
  registered actions with audit; bulk-accept is explicit and enumerated;
  no silent promotion path exists (gate-bound denial row).
- **Zero egress.** Sources are local stores; the optional extraction
  model is the configured local model only (LD-R5); a transport-counter
  eval row pins it.
- **Sensitive content never becomes memory.** The intent-side secret
  blocklist generalizes to consolidation; `Security.Redactor` covers run
  summaries and audit lines; filter hits are counted, not stored.
- **Model output never originates a fact.** Extraction reads
  operator-authored turns only (LD-19); assistant turns are
  disambiguation context. Allbert's own speculation cannot return as a
  proposal wearing real provenance.
- **Retirement is as consent-bound as creation.** No code path retires a
  `:kept` fact except operator review; consolidation writes supersession
  proposals that change nothing until reviewed.
- **Nothing is destroyed.** Superseded facts are retired in place with an
  auditable chain, never deleted or overwritten — the preserve-user-data
  rule applied to the memory subsystem.
- STM data-safety contract narrows what may transit working memory;
  nothing new persists.

## Non-Goals

- Embedding-backed retrieval, learned ranking, trained memory artifacts
  (System Memory Distillation stays parked).
- Inferred temporal queries: as-of is an explicit parameter, never
  resolved from natural language; multi-hop temporal reasoning ("what did
  I drive before this one") is out of scope (ADR 0089 §7).
- System-initiated invalidation: consolidation proposes retirement and
  never enacts it.
- Relaxing explicit review for any class of entries (a future ADR 0089
  amendment could — with operator sign-off; not in 1.3).
- Widening the prompt seam beyond direct-answer/vision.
- Conversation retention/pruning changes; message-store rewrites.
- Cross-device or remote memory sync; multi-user semantics.
- Migration-runner pull-forward; any non-additive schema change.
- v1.4's profiling/suggestion loop (same sources, separate release and
  ADR).

## Validation Design (churn guardrails, binding)

Identical contract to v1.2 (the v1.1 M12.4–M12.13 lessons), instantiated:

1. No validation-only product capability; FV uses the product as an
   operator would.
2. The flagship scenarios — seeded-history consolidation→review→zero-shot
   and proposed-never-in-prompt — are CI regressions (M3/M6) before FV
   exists.
3. Behavioral eval rows + meta-contract; no template-only corpora for
   measured claims (the M12.8 lesson — precision floors are measured on
   real fixtures).
4. Explicit surface census for review UX (web panel, CLI) in the matrix
   suites.
5. Disposable Homes; no `~/.allbert`; no `set -e`; paste-executable rows.
6. FV opens once after the green authoritative gate at the candidate SHA;
   fixed corrective loop; no row renumbering.
