## §A — Rebuild (the only page-authoring path)

```
operator: allbert knowledge rebuild
  | (or tile action, or managed rebuild entry)
  v
knowledge_rebuild action  (Registry -> Runner)
  |
  +-- knowledge.enabled false? -> {:ok, status: :advisory, "Knowledge is off"}
  |
  +-- read current kept claims       (existing Memory read authority)
  +-- group by subject               (granularity: min_claims / min_inbound_refs)
  +-- emit typed page structs        (Knowledge.Page)
  +-- resolve cross-references       (relative markdown paths)
  +-- compute backlinks              (symmetric)
  +-- open NEW generation            (v1.3 projection machinery)
  +-- write pages, index.md, .graph.json
  +-- promote generation, retire previous
  v
{:ok, %{pages: N, generation: G, diverged: [...]}}
```

**Divergence short-circuit.** Before writing, each existing page's on-disk digest
is compared to its recorded digest. Diverged pages are excluded from the write
set and returned in `diverged`. Rebuild never overwrites them (LD 7).

**Failure modes**

| Condition | Outcome |
| --- | --- |
| Claim read denied | `{:error, :memory_read_denied}`; no generation opened |
| Generation write fails mid-way | Previous generation retained; new generation discarded; rebuild is atomic at generation granularity |
| Redaction check fails on any page | Whole rebuild aborts; the page is never written |
| `max_pages` exceeded | Rebuild aborts with `{:error, {:page_ceiling_exceeded, count}}`; operator raises the ceiling or tightens granularity |

## §B — Query (Stage 1 scope: own pages only)

```
operator: allbert knowledge query "attention"
  v
knowledge_query action
  +-- lexical match over page titles, frontmatter, body
  +-- rank deterministically (no model, no embedding)
  +-- return page paths + snippet + provenance claim ids
  v
{:ok, %{results: [...], layer: :knowledge_pages}}
```

`layer: :knowledge_pages` is emitted from day one even though Stage 1 has only
one layer, so the Stage 2 composite (ADR 0094 §9) is an additive change to the
result shape rather than a breaking one.

**Stage 1 must not** consult Memory retrieval or Search Central (LD 10).

## §C — Lint

```
operator: allbert knowledge lint
  v
knowledge_lint action  — zero model calls (LD 9)
  |
  +-- contradictions   two current kept claims, same subject+predicate,
  |                    incompatible values
  +-- orphans          page with no inbound links
  +-- unresolved       relative link with no target on disk
  +-- stale            page whose source claims were superseded after `updated`
  +-- underpopulated   page below knowledge.page.min_claims
  v
{:ok, %{findings: [...], by_class: %{...}}}
```

Findings are returned, not written as files. Stage 1 has no `outputs/` directory
and no `log.md` — both are Stage 2.

## §D — Edit divergence and promotion

```
operator edits <HOME>/projections/knowledge/concepts/rag.md in any editor
  v
next rebuild (or `allbert knowledge status`)
  +-- digest mismatch detected
  v
surface: "concepts/rag.md was edited outside Allbert."
  [Promote to memory claim]  [Save as note]  [Discard]  [Keep, stop maintaining]
```

| Choice | Path | Authority |
| --- | --- | --- |
| Promote to claim | `knowledge_promote_edit` emits a **claim proposal** | v1.3 review flow — reviewed before it becomes kept |
| Save as note | `knowledge_promote_edit` routes to note write | v0.65 confirmation-gated write into the connected root |
| Discard | Page rejoins the write set on next rebuild | none |
| Keep, stop maintaining | Page recorded in `<HOME>/knowledge/promotions/` as operator-owned; excluded from rebuild; surfaced by lint as a fork | none |

**No third authority.** `knowledge_promote_edit` never writes a kept claim
directly and never bypasses the note confirmation.

## §E — Forget interaction

```
operator Forgets a claim (v1.3 path, unchanged)
  v
Forget replaces/retires affected projection generations
  +-- Memory projection    (existing)
  +-- Search projection    (existing)
  +-- Knowledge projection (NEW — same machinery, LD 1)
  v
pages derived from the forgotten claim are retired with their generation
```

A page cannot outlive the claim it derives from. This is inherited, not
reimplemented.

## §F — Security eval rows (`:v161`, gate-bound, behavioral)

| Row | Assertion |
| --- | --- |
| `knowledge-derived-no-authority-001` | A derived page grants no permission and is never read as policy input |
| `knowledge-redaction-parity-001` | Content redacted on a claim never appears on any page, under any page type |
| `knowledge-no-egress-001` | A full rebuild, query, and lint make zero network calls and zero model calls |
| `knowledge-promotion-review-001` | Claim promotion enters review and cannot become kept without it |
| `knowledge-promotion-note-confirm-001` | Note promotion is denied without confirmation |
| `knowledge-divergence-no-overwrite-001` | A diverged page survives rebuild unmodified |
| `knowledge-forget-retires-page-001` | Forgetting a contributing claim retires the derived page |
| `knowledge-disabled-clean-001` | `knowledge.enabled` false yields a clean advisory state on every surface, and no projection is written |
| `knowledge-export-exclusion-001` | Export excludes `projections/knowledge/` and includes `<HOME>/knowledge/`; restore rebuilds from claims |

## Smoke Checklist

```bash
# build a graph from a seeded claim corpus
allbert knowledge rebuild
# PASS: reports page count and generation; exit 0

# traverse without an editor
ls "$ALLBERT_HOME/projections/knowledge"
grep -c "^## Backlinks" "$ALLBERT_HOME"/projections/knowledge/concepts/*.md
# PASS: every page has a Backlinks section

# every relative link resolves
allbert knowledge lint
# PASS: unresolved-link class is empty on a clean graph

# divergence
printf '\nedited by hand\n' >> "$ALLBERT_HOME"/projections/knowledge/concepts/*.md
allbert knowledge rebuild
# PASS: reports the page as diverged; file still contains "edited by hand"

# disabled state
allbert admin settings set knowledge.enabled false
allbert knowledge query "anything"
# PASS: advisory status, exit 0, no projection written
```

## §G — Focused operator validation (FV, end of implementation)

### FV-01 — read your own knowledge in your own editor

Operator opens `<HOME>/projections/knowledge/index.md` in whatever they use —
vi, VS Code, TextMate — follows three relative links and one backlink, and lands
where expected. **Records:** editor used, links followed, whether any link failed
to resolve.

### FV-02 — lint finds a real contradiction

Operator seeds two conflicting kept claims through normal use, runs lint, and
confirms the contradiction is reported with both claim ids. **Records:** the
finding text and whether it was actionable without reading code.

### FV-03 — edit and promote

Operator edits a page, runs rebuild, and takes each of the four divergence
choices at least once across four pages. **Records:** whether any edit was lost,
and whether the promotion destinations were understandable.

### FV-04 — dual-host latency

The M6 calibration run repeated at the release candidate on packaged macOS arm64
and packaged Linux x86_64. **Records:** four rows, per host, neither averaged.
